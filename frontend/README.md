# Sunny Frontend

React + Vite frontend for the Sunny OCR assignment.

## Development

- `npm install`
- `npm run dev`

App runs at `http://localhost:4200`.

## Build

- `npm run build`
- `npm run preview`

## API Base URL

By default the app calls `http://localhost:3000`.

To override, create `.env` in this folder:

- `VITE_API_BASE_URL=http://localhost:3000`
